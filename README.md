# BUC Public Website Showcase

Standalone, bilingual presentation build for the public website of the Faculty of Business & Economics.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite. To create the production build, run:

```bash
npm run build
```

## Public experience

- Homepage
- About the Faculty
- Academic programs and ten program-detail pages
- Admissions and transfers
- Student life and services
- Career and training
- News, events and article-detail pages
- Alumni stories
- Contact
- Separate Smart Faculty Portal sign-in screen

The app stores the selected Arabic or English language in the browser and has no backend or database dependency.

## Internal registers

- `content-source-register.md` lists content that requires official Faculty confirmation before public publication.
- `image-asset-register.md` documents generated website photography and its production direction.
